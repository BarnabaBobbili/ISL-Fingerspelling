Training, decoding and key frames

Training​

python src/training/build_cont_features.py            # features for all 1,308 videos (2.5 min)
python src/training/train_cont_v2.py --kind conformer --parts all --tag conformer_all --bs 32 --epochs 60
SettingValue
Data1,308 videos split by video: train / validation / test as in the dataset (see Datasets)
Normalisationper-dimension mean/std of the training frames, stored in the checkpoint
LossCTC (blank = 26, zero_infinity) + 0.3 × intermediate CTC (Conformer)
OptimiserAdamW, weight decay 10⁻², one-cycle schedule, lr 7·10⁻⁴ (Conformer) / 1.5·10⁻³ (BiLSTM)
Batch / epochs32 sequences, up to 60 epochs, early stopping on validation CER (patience 12)
Model selectionlowest validation CER; the test set is touched once at the end

Decoding​

Greedy CTC decoding: take the arg-max class of every frame, merge repeated labels, drop blanks. src/pipeline/ctc.py: greedy_with_pos additionally returns, for each emitted letter, the frame of maximum probability inside its run — the letter's key frame.

One key frame per letter​

For an uploaded video:

  1. every frame → hands → features → log-probabilities (T × 27);
  2. greedy decoding gives the letters and their peak frames;
  3. each peak frame is saved as a thumbnail (keyframes/NN_X.jpg) with timestamp and confidence (the posterior at the peak);
  4. the annotated video types each letter at its peak frame.

(ctc.forced_align — Viterbi alignment of a known transcript — is used offline to build the aligned real frames.)

Live webcam​

In the application the continuous model runs as a streaming decoder: landmarks are resampled to 30 Hz, a sliding window is re-decoded every second frame, and letters are committed once they are 0.4 s old. The mechanism is described in Live streaming. The server-side cost of one landmark packet (features and decoding) is about 5 ms; hand tracking itself runs in the browser.

No space symbol

Spaces are removed from the transcripts, so the model cannot emit them. Word breaks in live mode come from a pause rule: the word ends when the hands are out of view for about 1 s.
