ISL fingerspelling

ISL fingerspelling is a system that recognises and generates Indian Sign Language (ISL) fingerspelling, the A–Z manual alphabet used to spell names and words. It works in both directions:

DirectionWhat it doesWhere
Sign → text / speechReads letters from a live webcam or an uploaded video, shows the letter and its confidence score on top of the video, builds the text and can speak itRecognise page (live camera or a video file)
Text / speech → signTurns typed or dictated text into 3D hands that sign it letter by letter, with the current character shown on topSign page
Every characterA reference of all 26 letters rendered on the 3D hands (one-handed or two-handed, contact points)Alphabet page

What is inside​

  • Static recognition — DH-GAT. A Dual-Hand Graph Attention network that represents both hands in one coordinate frame and models which finger touches which part of the other hand. Confidence scores are calibrated.
  • Continuous recognition — Conformer-CTC / BiLSTM-CTC. Reads flowing fingerspelling (names, words) from video without requiring pauses, and extracts one key frame per letter.
  • Video and webcam pipeline. MediaPipe hand tracking — in the browser for the live camera — → classifier → text, drawn as a HUD on top of the video. The live decoder commits letters about 0.4 s after they are signed and keeps up with fast signing and slow cameras (Live streaming).
  • 3D hands. Two skinned hands with sleeves (not a skeleton), animated between letter poses, using geometric transformations — rigid alignment (Kabsch) and finger inverse kinematics (FABRIK) — to make the joining points touch.
  • Web application. A single-page site (light and dark themes) with this manual built in, served by a small Python back end. All processing runs on the local computer.

Evaluation protocol

Static recognition is reported under three tests instead of one, because a random split of the training images considerably overestimates real-world accuracy. See Benchmark and Limitations.
