Benchmark

All numbers are produced by scripts in the repository and written into this page by src/evaluation/make_benchmark_doc.py from the files in results/. Nothing is typed by hand.

Static letters​

Three tests are always reported together (see design decision DD-008):

TestWhat it measures
In-domainthe original random split of ≈ 45 k images (near-duplicate frames: optimistic)
Real news video1,069 letter frames CTC-aligned from held-out test videos (small hands, full-body shot)
Cross-sourcetrain without ISL_DATA, test on all 13,061 of its images (new camera, background, signer)

Continuous fingerspelling​

Character error rate (CER = edit distance / reference length, corpus level, greedy CTC decoding) on the validation and test videos of the dataset:

ModelParametersValidation CERTest CER
BiLSTM-CTC v1 (63-d landmarks, one hand)—14.24 %14.75 %
Conformer-CTC v1 (63-d landmarks, one hand)—18.72 %19.26 %
BiLSTM-CTC v2 — features: all (351-d)1,469,0496.30 %4.28 %
BiLSTM-CTC v2 — ablation: raw geometry + motion only (133-d)1,437,2216.85 %5.12 %
Conformer-CTC v2 — features: all (351-d)2,569,1405.75 %3.91 %
Conformer-CTC v2 — ablation: raw geometry + motion only (133-d)2,537,3127.67 %5.91 %
Conformer-CTC v2 — features: all (351-d) + streaming training (deployed)2,569,1405.94 %3.63 %
  • The v1 Conformer was worse than the v1 BiLSTM. The v2 features (pretrained hand-shape embedding + both hands + motion), augmentation, a smaller convolution kernel and the intermediate CTC loss turn this around.
  • The ablation rows use no trunk/posterior features at all, so the difference to the "all features" rows is what the pretrained DH-GAT contributes: Conformer test CER 5.91 % → 3.91 %; BiLSTM test CER 5.12 % → 4.28 %.
  • Without the pretrained features the Conformer is not better than the BiLSTM — consistent with Conformers needing more data than the ≈ 70 minutes available. The pretrained hand-shape embedding supplies the missing prior, which is why the Conformer becomes the best model only with it.
  • Validation CER selects the model; the test set is used once.

Live decoding​

Faster signing time-compresses the hand track; slower cameras drop frames and keep true timestamps. A letter is final about 0.4 s after it was signed. The previous model is the one trained without the streaming augmentations.
