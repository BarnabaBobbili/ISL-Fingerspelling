Quick start

1 · Start the web app​

python app/server.py            # http://127.0.0.1:8000

Open http://127.0.0.1:8000. The status badge (top right) turns green — models ready — after a few seconds.

2 · Try the pages​

PageTry this
Recognise → Live cameraStart camera and spell a name at a normal pace (flowing mode), or choose Single letters and hold each one still for about a third of a second. The letter, a confidence meter and the top-3 alternatives are drawn over the video; the text appears below, newest letters greyed until they settle.
Recognise → Video fileDrop any video. Click a key-frame thumbnail to jump to that letter.
SignType NAMASTE INDIA, press Sign it. Toggle Bring touching joints together to compare raw and corrected poses.
AlphabetAll 26 letters on the signer; click one for a larger view.
Results / DocsThe measured numbers, and this manual.

3 · Use the command line instead​

# analyse a video (writes key frames + annotated video to results/video_out/<name>/)
python -m src.pipeline.cli video my_clip.mp4 --mode static
python -m src.pipeline.cli video my_clip.mp4 --mode continuous

# webcam in an OpenCV window  (q quit · c clear · space · b backspace)
python -m src.pipeline.cli webcam

4 · Tips for good recognition​

  • Show both hands in the picture when the letter needs them (20 of 26 letters are two-handed — see Pose library).
  • Keep the hands inside the frame, reasonably large, with a plain background and good light.
  • In static mode hold the sign still. To type the same letter twice, drop the hands slightly between the two signs (or keep holding for 1.6 s).
  • Remove your hands for about a second to end a word (flowing mode) or ≈ 1.4 s to insert a space (held-letter mode).
